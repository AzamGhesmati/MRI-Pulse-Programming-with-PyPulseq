# MRI Pulse Programming with PyPulseq

### Learning and Developing MRI Pulse Sequences Using Python

This repository documents a practical journey into Magnetic Resonance Imaging (MRI) pulse sequence programming using Python and [PyPulseq](https://github.com/imr-framework/pypulseq).

The main objective is to develop a deeper understanding of MRI sequence design, RF excitation, gradient waveforms, k-space encoding, and quantitative MRI techniques through computational implementation and simulation.

## Research Interests

- MRI Pulse Sequence Programming
- Quantitative MRI (qMRI)
- Magnetic Resonance Fingerprinting (MRF)
- RF Pulse Design
- Gradient Encoding and K-space Trajectories
- T1 and T2 Mapping
- MRI Signal Simulation

## Background

My academic background is in Biomedical Physics, with research interests in Magnetic Resonance Imaging, NMR relaxometry, quantitative imaging, and magnetic resonance fingerprinting.

This project is intended to connect theoretical MRI physics with practical pulse sequence programming and computational research.

## Project Goals

1. Understand the physics behind MRI pulse sequences.
2. Implement basic MRI sequences using PyPulseq.
3. Visualize RF and gradient waveforms.
4. Calculate and analyze k-space trajectories.
5. Explore quantitative MRI sequence design.
6. Develop a foundation for implementing MR Fingerprinting sequences.
